# 说明

**这个RSI主要是用于做什么的？**

给你一个模型和给定硬件，在该硬件下部署该模型的最佳实践是什么。-->**DeepResearchRSI**调研外部该模型在该硬件条件下部署的最佳实践。-->**ReproduceRSI**针对这个最佳实践进行复现。-->**OptimizationRSI**针对别人的最佳实践进行优化。

**如何定义你的实践就是最佳实践？**

在给定输入输出，满足SLA的情况下：

| 相对基准的有效吞吐提升 | 评价等级     | 是否足以支持最佳实践主张         |
| ---------------------- | ------------ | -------------------------------- |
| 0～5%                  | 微小优化     | 不足以单独证明                   |
| 5～10%                 | 有效优化     | 可以说明有所改进                 |
| 10～20%                | 显著优化     | 有较强竞争力                     |
| **20～30%**            | **领先优化** | **有充分理由提出领先方案**       |
| 30～50%                | 大幅领先     | 很有说服力                       |
| 50% 以上               | 卓越优化     | 如果测试公平，属于非常突出的结果 |

三级SLA：

- **InferX Base:** TTFT <= 2s, TPOT <= 70 ms
- **InferX Pro:** TTFT <= 1.5s, TPOT <= 50 ms
- **InferX Max:** TTFT <= 1s, TPOT <= 30 ms
